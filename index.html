A lightweight Minecraft launcher

Orvex Client is a custom launcher for Minecraft Java Edition. It handles secure authentication, launches the game with your mods, and stays out of your way.

Download (soon) Learn more

What it does

Secure login

Sign in securely with your Microsoft / Xbox account. Passwords never touch the launcher.

Fabric ready

Detects your installed Fabric loader and launches it with the correct Java arguments.

Built-in mods

Comes with a custom Minecraft mod featuring a click GUI, toggle sprint, full bright, and more modules – just like other clients.

Uses .minecraft

Works with your existing .minecraft folder. No separate installation required.

🛠️ Development build

This launcher is actively being built. It works for local testing, but the Microsoft API approval is still pending. Once approved, you'll be able to log in with your real Minecraft account.
