חזרה אל Orvex Client ←

מדיניות פרטיות

עדכון אחרון: אוגוסט 2026

בקצרה: Orvex Client אינו אוסף, שומר או משתף מידע אישי. סיסמת Microsoft שלכם לעולם אינה עוברת דרך המפעיל. כל תהליך האימות מתבצע ישירות מול Microsoft.

1. מידע שאיננו אוספים

Orvex Client אינו אוסף, שומר או משדר אף אחד מהפרטים הבאים:

  • כתובת הדוא"ל או הסיסמה של חשבון Microsoft שלכם
  • שם המשתמש שלכם ב-Minecraft, מזהה UUID או אסימון גישה (למעט אחסון מקומי לצורך הפעלת המשחק)
  • כתובת ה-IP שלכם
  • מידע על החומרה שלכם
  • נתוני המשחק שלכם או הפעילות שלכם בשרתים

2. אימות

האימות מתבצע כולו דרך דף הכניסה הרשמי של Microsoft המשתמש ב-OAuth 2.0. בעת התחברות, אתם מופנים לשרתים של Microsoft, שם אתם מזינים את פרטי הכניסה שלכם. Orvex Client לעולם אינו רואה את הסיסמה שלכם.

לאחר התחברות מוצלחת, Microsoft מספקת למפעיל אסימוני גישה זמניים. אסימונים אלה נשמרים באופן מקומי במחשב שלכם (בתיקיית התצורה של המפעיל), כדי שלא תצטרכו להתחבר בכל פעם. הם לעולם אינם נשלחים לשרת כלשהו שבבעלות צוות Orvex Client.

3. אחסון נתונים מקומי

המפעיל שומר את הנתונים הבאים במחשב המקומי שלכם בלבד:

  • אסימון הגישה ואסימון הרענון של Microsoft (מוצפנים באמצעות MSAL)
  • הגדרות המפעיל (נתיב Java, הקצאת זיכרון וכדומה)
  • תצורת המודים שלכם (מצבי מודולים, קיצורי מקשים)

נתונים אלה לעולם אינם יוצאים מהמחשב שלכם.

4. שירותי צד שלישי

Orvex Client מתקשר רק עם השירותים הרשמיים הבאים:

  • Microsoft Identity Platform (login.microsoftonline.com) – לצורך אימות
  • Xbox Live (xboxlive.com) – לצורך אימות החשבון
  • Minecraft Services API (api.minecraftservices.com) – לצורך אסימוני הפעלת המשחק
  • Mojang Resources (resources.download.minecraft.net) – להורדת נכסי המשחק

איננו משלבים שירותי ניתוח נתונים, פרסום או מעקב.

5. מחיקת נתונים

ניתן למחוק את כל הנתונים המאוחסנים מקומית בכל עת באמצעות:

  • שימוש בלחצן "התנתקות" במפעיל (מסיר את האסימונים)
  • מחיקת תיקיית התצורה של המפעיל (%AppData%\OrvexClient)

6. פרטיות ילדים

Orvex Client אינו אוסף ביודעין מידע מאיש. הוא מתאים לכל הגילים.

7. שינויים במדיניות זו

ייתכן שנעדכן את מדיניות הפרטיות מעת לעת. כל שינוי יפורסם בעמוד זה.
