プライバシーポリシー

最終更新日：2026年8月

概要：Orvex Client は個人データを収集、保存、共有しません。Microsoft のパスワードがランチャーに渡ることはありません。認証はすべて Microsoft が直接処理します。

1. 収集しない情報

Orvex Client は、以下の情報を収集、保存、送信しません。

  • Microsoft アカウントのメールアドレスまたはパスワード
  • Minecraft のユーザー名、UUID、アクセス トークン（ゲーム起動のためローカルで保存する場合を除く）
  • IP アドレス
  • ハードウェア情報
  • ゲームの統計情報やサーバー上の活動

2. 認証

認証は Microsoft の公式 OAuth 2.0 サインインページを通じて行われます。サインイン時は Microsoft のサーバーに移動し、そこで認証情報を入力します。Orvex Client がパスワードを見ることはありません。

サインインが完了すると、Microsoft は一時的なアクセス トークンをランチャーに提供します。毎回サインインしなくて済むよう、トークンはお使いのコンピューター上（ランチャーの設定フォルダー内）にのみ保存されます。Orvex Client チームが所有するサーバーに送信されることはありません。

3. ローカルデータの保存

ランチャーは以下のデータのみをお使いのコンピューターに保存します。

  • Microsoft のアクセス トークンとリフレッシュ トークン（MSAL により暗号化）
  • ランチャーの設定（Java のパス、メモリ割り当てなど）
  • Mod の設定（モジュールの状態、キー割り当て）

これらのデータがコンピューターの外に送信されることはありません。

4. サードパーティ サービス

Orvex Client は以下の公式サービスとのみ通信します。

  • Microsoft Identity Platform（login.microsoftonline.com）— 認証
  • Xbox Live（xboxlive.com）— アカウント確認
  • Minecraft Services API（api.minecraftservices.com）— ゲーム起動トークン
  • Mojang Resources（resources.download.minecraft.net）— ゲームアセットのダウンロード

分析、広告、追跡サービスは利用していません。

5. データの削除

以下の方法で、ローカルに保存されたデータをいつでも削除できます。

  • ランチャーの「ログアウト」ボタンを使用する（トークンを削除）
  • ランチャーの設定フォルダー（%AppData%\OrvexClient）を削除する

6. 子どものプライバシー

Orvex Client は、誰からも情報を故意に収集しません。年齢を問わずご利用いただけます。

7. 本ポリシーの変更

プライバシーポリシーを随時更新することがあります。変更はこのページに掲載します。

8. お問い合わせ

本ポリシーについて質問がある場合は、GitHub リポジトリで issue を作成してください。

Orvex Client · Mojang および Microsoft とは提携していません。
