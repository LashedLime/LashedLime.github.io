Легкий клиент Minecraft, который не мешает игре

Входите в аккаунт, устанавливайте Minecraft и Fabric, управляйте модами и запускайте игру из одного места. Orvex создан для низкого потребления ресурсов, чтобы компьютер мог сосредоточиться на игре.

Скачать Узнать больше

Без рекламы и телеметрии. Файлы игры хранятся отдельно от стандартной папки .minecraft.

Что он умеет

Всё необходимое для запуска Minecraft — без лишней фоновой нагрузки.

Безопасный вход

Безопасный вход в аккаунт Microsoft. Orvex никогда не обрабатывает ваш пароль.

Полная автономия

Minecraft, Fabric, ресурсы и Java устанавливаются в отдельную директорию Orvex, не затрагивая вашу текущую конфигурацию.

Легкий и экономичный

Низкое потребление ресурсов в простое оставляет больше возможностей для Minecraft.

Восстановление в один клик

Восстановите отсутствующие или поврежденные файлы клиента одним нажатием — без ручной очистки.

Быстрый старт

Авторизуйтесь один раз, и клиент всё сделает сам. Minecraft, Fabric и Java скачиваются автоматически при первом нажатии кнопки «Играть».
