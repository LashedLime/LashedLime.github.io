Политика конфиденциальности

Последнее обновление: август 2026 г.

Кратко: Orvex Client не собирает, не хранит и не передает персональные данные. Ваш пароль Microsoft никогда не проходит через наш лаунчер. Вся аутентификация выполняется напрямую Microsoft.

1. Какие данные мы НЕ собираем

Orvex Client не собирает, не хранит и не передает следующие данные:

  • Адрес электронной почты или пароль вашей учетной записи Microsoft
  • Имя пользователя Minecraft, UUID или токен доступа (кроме локального хранения для запуска игры)
  • Ваш IP-адрес
  • Информацию об оборудовании
  • Статистику игрового процесса или активность на серверах

2. Аутентификация

Аутентификация полностью выполняется через официальную страницу входа Microsoft с использованием OAuth 2.0. При входе вы перенаправляетесь на серверы Microsoft, где вводите свои учетные данные. Orvex Client никогда не видит ваш пароль.

После успешного входа Microsoft предоставляет лаунчеру временные токены доступа. Они хранятся только локально на вашем компьютере (в папке конфигурации лаунчера), чтобы вам не приходилось входить каждый раз. Эти токены никогда не отправляются на серверы команды Orvex Client.

3. Локальное хранение данных

Лаунчер хранит только на вашем компьютере следующие данные:

  • Токен доступа Microsoft и токен обновления (зашифрованы с помощью MSAL)
  • Настройки лаунчера (путь к Java, выделение памяти и т. д.)
  • Настройки модов (состояние модулей, клавиши быстрого доступа)

Эти данные никогда не покидают ваш компьютер.

4. Сторонние сервисы

Orvex Client взаимодействует только со следующими официальными сервисами:

  • Microsoft Identity Platform (login.microsoftonline.com) — для аутентификации
  • Xbox Live (xboxlive.com) — для проверки учетной записи
  • Minecraft Services API (api.minecraftservices.com) — для получения токенов запуска игры
  • Mojang Resources (resources.download.minecraft.net) — для загрузки игровых ресурсов

Мы не используем сервисы аналитики, рекламы или отслеживания.

5. Удаление данных

Вы можете в любое время удалить все данные, хранящиеся локально:

  • Нажмите кнопку «Выйти» в лаунчере (удаляет токены)
  • Удалите папку конфигурации лаунчера (%AppData%\OrvexClient)

6. Конфиденциальность детей

Orvex Client сознательно не собирает информацию ни о ком. Приложение подходит для всех возрастов.

7. Изменения политики

Мы можем время от времени обновлять настоящую Политику конфиденциальности. Все изменения будут опубликованы на этой странице.

8. Контакты

Если у вас есть вопросы об этой Политике конфиденциальности, создайте issue в нашем репозитории GitHub.
